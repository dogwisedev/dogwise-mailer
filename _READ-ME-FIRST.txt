UPLOAD 1 of 2 — brand new files. Nothing here overwrites anything.

Drag the CONTENTS of this folder onto your repo root (lib/ and api/ will merge).
Then commit and deploy. Nothing changes for users: this code is present but
nothing calls it yet.

  lib/marketing.js    build a marketing email for one recipient
  lib/designs.js      store designs in Redis (own keys, not the campaigns blob)
  lib/spamcheck.js    deliverability preflight linter
  lib/throttle.js     per-sender caps (defaults never fire at normal volume)
  lib/bounces.js      bounce classification + suppression list
  api/designs.js      design save/load endpoint
  api/unsubscribe.js  public opt-out page
  api/bounce-sweep.js hourly bounce sweep
  .vercelignore       keeps builder source out of the deploy

Verify after deploy:  GET /api/designs  ->  {"designs":[], ...}

Environment variables to add in Vercel (all optional except the first two if you
want a proper footer):

  BRAND_ADDRESS=<physical mailing address, required by CAN-SPAM in marketing email>
  BRAND_DOMAIN=dogwiseacademy.com
  MARKETING_DAILY_CAP=400
  MARKETING_PER_TICK=20
  MARKETING_WARMUP_START=      leave BLANK unless you want a slow ramp
